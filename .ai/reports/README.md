# .ai/reports

This folder contains machine-consumable reports generated by CI when executing `.ai/requests/*.yaml` files.

Do not edit generated `.yaml` reports manually — they should be produced by `ci-ai-request-runner.yml` on a self-hosted runner and then optionally read by `ci-ai-feedback.yml` to notify AI Studio.

Example report entries:

```yaml
metadata:
  request_id: "ai-req-2025-12-01-live-dashboard"
  request_file: ".ai/requests/live-dashboard-smoke.yaml"
  target_env: "dev-local"
  git_sha: "<commit>"
  git_branch: "ai/live-dashboard-2025-12-01"
  workflow_run: "<run-id>"
status: "success"   # or failed
started_at: "2025-12-01T10:00:00Z"
completed_at: "2025-12-01T10:01:30Z"
results:
  command_0:
    status: success
    exit_code: 0
    duration_seconds: 30
    log_tail: "..."
artifacts:
  playwrght_report: "reports/playwright-report.zip"
  logs: "reports/latest.log"
```
